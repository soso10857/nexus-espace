3. Qualité des données & sécurité

Les clés API enregistrées dans un navigateur ne sont pas protégées comme dans un serveur privé. Ne publie jamais de clé dans le code HTML, GitHub ou une capture d'écran. Pour un déploiement public durable, il faudra un petit serveur intermédiaire (proxy) qui garde les clés hors du navigateur.
  • Chaque donnée doit afficher sa source, sa date et son éventuel délai.
  • Une valeur absente ne sera pas remplacée par un chiffre inventé.
  • Les données indisponibles selon le forfait seront signalées comme telles.
  • Les graphiques locaux fonctionnent hors ligne ; leurs cours sont simulés et ne représentent pas les prix de marché.
  • Les transactions du portefeuille sont toujours fictives.
