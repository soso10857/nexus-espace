Données & synchronisation

Les deux applications utilisent une clé de stockage locale commune dans le même navigateur et sur la même origine. Les changements sont synchronisés lors des événements de stockage.

Les données de cet espace sont conservées localement dans ce navigateur. NEXUS ne se connecte à aucun établissement bancaire.

Accès & protection

Cette page ne collecte aucun mot de passe. Le navigateur peut conserver les données localement. Un code PIN côté interface ne remplace pas un chiffrement ou une authentification sécurisée.
